# asp_Contract

Module de gestion des contrats.

- Création de produit contrats
- Création de contrats. Un contrat sera allimenté d'un produit correspondant à une prestation lui même composé de plusieurs services
- Une ligne de facturation sera générée pour chaque période.

## Dépendances
- company
- account
- product
- account_product
- sale
- sale_discount
